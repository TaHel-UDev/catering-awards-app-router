## Лауреаты и видеоархив

Блок «Лауреаты» (`laureates_section`) расположен после победителей и перед фотоархивом.
В Directus редактируются видимость блока, заголовок, подзаголовок, список компаний,
порядок компаний, переключатель «Выделить ярче и жирнее» и строка городов.
Городов может быть любое количество: размер шрифта задаётся отдельно для
компьютеров и телефонов (10–32 px). По умолчанию города прокручиваются непрерывной
бегущей строкой. В Directus можно отключить прокрутку или задать длительность
полного прохода (10–180 секунд; больше число — медленнее движение).
По умолчанию полный проход занимает 60 секунд. Наведение на текст или фокус
с клавиатуры приостанавливает движение. При системной настройке уменьшения движения
города показываются обычным текстом с переносами. Enter задаёт явный перенос
в обычном режиме; в бегущей строке переносы заменяются разделителями.
Названия компаний и города — обычный текст без ссылок. Пустой список или выключенная
видимость скрывают блок. Данные загружаются вместе с остальными разделами страницы.

В фотоархиве ссылки на видео VK автоматически открывают модальное окно с плеером.
Альбомы и остальные ссылки сохраняют переход в новую вкладку. Поддерживаются
`vk.com`, `vk.ru`, `vkvideo.ru`, ссылки `video_ext.php` и параметр `z=video…`.
Для ролика можно указать необязательную «Ссылку на VK-плеер»: значение `src` из
кода встраивания VK с параметром `hash`. Исходная ссылка остаётся доступной в окне
плеера. Закрытие окна удаляет iframe и останавливает воспроизведение.

Для первичной настройки другой базы Directus:

```powershell
# .env: NEXT_PUBLIC_DIRECTUS_URL и DIRECTUS_ADMIN_TOKEN (только на сервере)
npm run cms:setup-laureates
```

Скрипт добавляет коллекцию, начальные тексты из задания, русские подписи полей,
доступ на чтение для публичной политики и права редактора по образцу фотоархива.
Повторный запуск сохраняет уже введённый контент и существующие права.
Административный токен используется только скриптом и не попадает в браузер.

Проверки: `npm run test:gallery`, `npx tsc --noEmit`, `npm run build`.

## Предварительные заявки при закрытой регистрации

В настройках кнопки первого экрана, карточек гостей/номинантов или нижнего блока
выберите действие **«Регистрация закрыта — предварительная заявка»**, задайте текст
кнопки «Узнать об открытии регистрации» и выберите соответствующую форму.
Открытые ссылки на регистрацию продолжают работать независимо от этого режима.

В коллекции **«Формы»** подготовлены формы «Предварительная заявка — гость»,
«Предварительная заявка — номинант» и «Предварительная заявка — выбор участия».
Для гостя и номинанта тип участия фиксируется в настройках формы; в общей форме
посетитель выбирает его сам. Все шесть полей обязательны: имя, фамилия, компания,
город, контактный телефон и email. Заголовок, пояснение, текст отправки и сообщение
после отправки редактируются в форме. Персональные данные и согласие проверяются
также на сервере; тип заявки и участия берутся из актуальных настроек Directus.

В **«Глобальных настройках»** отдельные поля **«Предварительные заявки: получатели»**
и **«Предварительные заявки: копия»** управляют адресами To/Cc. Изменения действуют
со следующей отправки. Обычные заявки используют прежний список получателей.

В **«Заявках»** сохраняются все поля, источник, тип заявки и отметка «гость/номинант».
В теме письма предварительная заявка и тип участия также обозначены явно.
Статус «Отправлено» означает приём письма почтовым сервером. При ошибке SMTP
заявка остаётся в базе со статусом «Ошибка отправки» — проверьте настройки почты
и свяжитесь с участником по сохранённым контактам. Автоматическая повторная
отправка писем не выполняется.

Настройка другой базы: `npm run cms:setup-pre-registration` (серверные переменные
`NEXT_PUBLIC_DIRECTUS_URL` и `DIRECTUS_ADMIN_TOKEN`). Скрипт добавляет схему и
формы, сохраняет существующие настройки и включает предварительную форму только
для кнопок без действующей ссылки/формы. После настройки укажите адреса To/Cc
в «Глобальных настройках». Проверка обработки заявок: `npm run test:applications`.

## Фоновое видео первого экрана

В коллекции **«Первый экран»** (`hero_section`) подготовлена вкладка **«Фон первого
экрана»**: включение видео, основной MP4, дополнительный WebM, облегчённый мобильный
MP4, изображение-заставка и затемнение (0–90%). Пока схема не применена, отсутствие
этих полей сохраняет прежний фон. Скрипт не загружает файлы, не включает видео и
не меняет тексты или настройки регистрации.

```powershell
# Только показать план: запросы чтения, без изменения рабочего Directus
npm run cms:setup-hero-video

# Применить схему только после согласования
npm run cms:setup-hero-video -- --apply
```

Основной ролик: **MP4 с H.264**, цветовой формат `yuv420p`, без звуковой дорожки,
10–30 секунд, до 1920×1080, желательно до 10–15 МБ и с `faststart` для быстрого
старта. Одно расширение `.mp4` не гарантирует совместимость: MOV и HEVC сначала
нужно перекодировать. Дополнительный WebM (VP8/VP9) расширяет поддержку кодеков.
Для телефона можно загрузить отдельный MP4 до 720p и 3–5 МБ. Все файлы должны
быть доступны посетителям через обычный публичный `/assets/<id>` Directus.

Видео декоративное: без звука и элементов плеера, с повтором и `playsInline`.
На телефоне сначала пробуется мобильный MP4, затем основной MP4, затем WebM.
На компьютере — основной MP4, затем WebM. При ошибке источника пробуется следующий
формат; при запрете автовоспроизведения или отказе всех источников остаётся
заставка. Если файл зависает и не начинает воспроизведение за 12 секунд, пробуется
следующий источник. При ошибке заставки остаётся стандартный градиент сайта.

При системной настройке уменьшения движения и доступном сигнале экономии трафика
видеофайлы не запрашиваются. При уходе первого экрана из видимой области, скрытии
вкладки или открытии модального окна видео приостанавливается. Затемнение помогает
сохранить читаемость заголовка. Настройки и сам факт запуска автопроигрывания
контролирует браузер: [WebKit](https://webkit.org/blog/6784/new-video-policies-for-ios/),
[Chrome](https://developer.chrome.com/blog/autoplay).

Проверки схемы, форматов и настроек: `npm run test:hero-media`.
